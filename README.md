# Stock Market Sentiment Analysis Chatbot

An AI-powered chatbot designed to provide stock market insights, financial information, and intelligent responses to user queries. The system combines LLaMA-3 with sentiment analysis and real-time financial APIs to deliver relevant market information.

## Features

- 🤖 AI-powered chatbot using LLaMA-3
- 📊 Real-time stock market data
- 📰 Financial news retrieval
- 📈 Stock price and company information
- 💭 Sentiment analysis using NLTK VADER
- 🔴 Classifies news as Positive, Neutral, or Negative
- 🔗 Integration with Finnhub and Yahoo Finance APIs
- 🌐 Web-based interface using HTML5, CSS3, and JavaScript
- ⚡ FastAPI backend for efficient API handling

## Technologies Used

- Python
- FastAPI
- LLaMA-3
- NLTK VADER
- JavaScript
- HTML5
- CSS3
- Finnhub API
- Yahoo Finance API

## Project Objective

The project aims to combine artificial intelligence, natural language processing, and real-time financial data to help users understand stock market information and analyze the sentiment of financial news.

## Key Functionality

The chatbot accepts user queries related to selected companies and retrieves relevant stock prices, company details, and financial news. Financial news is processed using VADER sentiment analysis and classified into positive, neutral, or negative categories to provide additional market context.
